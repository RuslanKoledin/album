# Frontend Design Plugin

Provides general frontend visual-craft guidance. In Photobook work, combine it
with `skills/frontend-design/PROJECT_EXTENSION.md`; the project extension takes
precedence over generic aesthetic advice.

## What It Does

The generic skill helps with:

- coherent aesthetic direction;
- intentional typography, color, composition, and motion;
- production-ready visual implementation.

The project-specific
`../frontend/skills/photobook-design-review/SKILL.md` adds the required
Photobook UX workflow, constructor quality gates, accessibility checks, Figma
composition rule, and browser-based visual QA.

## Usage

```
"Create a dashboard for a music streaming app"
"Build a landing page for an AI security startup"
"Design a settings panel with dark mode"
```

For Photobook, prefer calm premium editorial design, restrained motion, and
customer-photo emphasis over the generic plugin's bolder defaults.
