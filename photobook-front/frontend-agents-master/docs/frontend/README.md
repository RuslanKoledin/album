# Photobook Frontend Memory

This folder is the starter UI memory installed into the Photobook frontend.
Keep it useful and small.

- `design-system.md`: durable visual direction and reusable tokens.
- `components.md`: meaningful reusable component inventory.
- `screens.md`: major routes, layouts, and recovery surfaces.
- `ui-decisions.md`: decisions that future work should not rediscover.
- `audit-checklist.md`: proportional UI completion checks.

Use `agent-assets/frontend/skills/photobook-design-review/SKILL.md` for the
default code-first implementation and browser review workflow. Figma remains an
optional artifact when explicitly useful, not a required parallel source.

Update these files when reusable tokens/components, major screens, or meaningful
visual behavior changes. Do not add records for trivial leaf markup or isolated
spacing corrections.
