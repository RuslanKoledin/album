# Photobook Frontend Agent Instructions

Правила применяются ко всем задачам в `photobook-front`. Явное решение
пользователя важнее проектных рекомендаций.

## Перед каждой задачей

1. Прочитать [карту документации](docs/README.md).
2. Прочитать единый файл [frontend-правил](docs/engineering/frontend.md).
3. Открыть только документы, относящиеся к задаче, по маршруту из карты.
4. Прочитать
   `frontend-agents-master/agent-assets/frontend/skills/frontend-agent/SKILL.md`.
5. Для UI использовать `photobook-design-review`; для ошибок, offline,
   загрузки, сохранения и оплаты — `frontend-error-ux`.

Не читать исторические и шаблонные материалы из `frontend-agents-master`, если
активный skill не ссылается на них напрямую.

## Выполнение

- Следовать текущему milestone из `docs/planning/roadmap.md` и брать ближайшую
  задачу из `docs/planning/frontend-backlog.md`.
- При работе с API, DTO, auth, upload, pricing, orders или jobs дополнительно
  читать `docs/engineering/backend.md` и соответствующие файлы `docs/api`.
- Обновлять постоянную документацию только при изменении правил, архитектуры,
  контракта, значимого flow или статуса backlog.
- Выполнять проверки, указанные в `docs/engineering/frontend.md`.
